<h2>📦 Instalación</h2>

<ol style="color: #d1d5db; font-size: 16px; line-height: 1.9;">
  <li>Descarga el archivo <a href="https://github.com/pablo96sancho/CleanBRUH/releases/latest">CleanBRUH-Installer.dmg</a></li>
  <li>Ábrelo y arrastra <code>CleanBRUH.app</code> a la carpeta <code>Aplicaciones</code></li>
  <li>Ejecuta la app y acepta los permisos de Accesibilidad que macOS te pida</li>
  <li>Pulsa <strong>Iniciar Limpieza</strong> desde la barra de menú</li>
</ol>

<hr style="margin: 30px 0; border: 0; border-top: 1px solid #2d3748;" />

<h2>🔒 Permisos</h2>

<p style="color: #d1d5db; font-size: 16px; line-height: 1.7;">
  CleanBRUH usa un <em>event tap</em> de macOS para bloquear la entrada del sistema, por eso necesita acceso a <strong>Accesibilidad</strong>.
  Si macOS no lo permite, ve a <strong>Ajustes del Sistema → Privacidad y seguridad → Accesibilidad</strong> y activa CleanBRUH.
</p>

<hr style="margin: 30px 0; border: 0; border-top: 1px solid #2d3748;" />
