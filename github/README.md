# CleanBRUH

Una app de menú para macOS que bloquea teclado, trackpad y ratón para que puedas limpiar tu equipo sin tocar nada.

## Download

- [Descargar CleanBRUH-Installer.dmg](CleanBRUH-Installer.dmg)

## Instalación

1. Descarga el archivo `.dmg`
2. Ábrelo y arrastra `CleanBRUH.app` a `Applications`
3. Abre la app y acepta los permisos de Accesibilidad cuando macOS los pida

## Cómo funciona

- Abre la app desde la barra de menú
- Pulsa en `Iniciar Limpieza`
- El teclado, el ratón y el trackpad quedan bloqueados
- Para salir, mantén pulsada la barra espaciadora durante 3 segundos

## Requisitos

- macOS 13 o superior
- Permisos de Accesibilidad

## Nota

CleanBRUH está pensado para limpiar y mantener el equipo sin que la entrada del sistema te interrumpa mientras trabajas.
